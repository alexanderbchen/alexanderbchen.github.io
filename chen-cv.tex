\begin{items}
	\item \textbf{\href{https://drive.google.com/file/d/1XI2BHCVpS4T-9Frp54UZE2bwBmct69Z1/view?usp=sharing}{2025 (Problem B).}} A Pressure-State-Response model ranking Super Bowl host cities by environmental footprint was built that identified Tampa as the most sustainable host. I led the data analysis by using ARIMA for emissions forecasting, AHP-CRITIC for weighting, TOPSIS for city-ranking, and MICE and random-forest imputation for missing indicators, and we were able to generalize our results to the NBA All-Star Weekend.

We used Monte Carlo simulation in Python to generate weighted inputs and logistic-growth curves to project the relevance of fast-emerging sports.\\[0.25em]
